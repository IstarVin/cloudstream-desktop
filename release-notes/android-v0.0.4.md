# Android 0.0.4

## Changes

- Add video quality selection with an Auto option and display the current video resolution.
- Keep playback running when a subtitle download fails, show a retryable error, and improve automatic and embedded subtitle selection.
- Keep subtitle text at a consistent size when moving it above player controls, including WebVTT captions.
- Load more titles while browsing home shelves, offer retries after loading errors, and retain collection pages and scroll position when returning from a title.
- Refresh player controls and panels, align shelf titles, and use rounded icons throughout the app.

## Server compatibility

Use server 0.0.3 or newer for server-side decryption of supported identity SAMPLE-AES fMP4 HLS streams.
