# Android 0.0.7

- Add media notifications, lock-screen and headset controls for playback, plus background controls and volume keys for a device you are controlling.
- Support local server sign-in with device approval and an optional password. Approve another device from Settings.
- Add repository URLs or shortcodes, validate them before saving, and browse plugins by repository with separate controls for same-named plugins.
- Save NSFW visibility separately on each device.
- Support intro, recap and outro skipping for TV shows with IMDb metadata through IntroDB, alongside AniSkip for anime.

## Upgrade

Use server 0.0.6 or newer for the new authentication, repository management and TV skip features. After upgrading the server, enable the plugins you want in Settings; plugin selection now starts empty.
