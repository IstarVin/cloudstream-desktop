# Android 0.0.3

## Fixes

- Align ASS subtitles with the video frame when the video and screen have different aspect ratios.

## Installation

- The Android application ID changed from `cloudstream.desktop.app` to `com.istarvin.cloudstream`. This version installs as a separate app rather than updating 0.0.2 in place. Pair with your desktop server again and reconfigure app preferences after installing.
