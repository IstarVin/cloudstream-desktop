# Android 0.0.1

Initial release of the Cloudstream Android phone, tablet, and TV client.

- Pair with your server using a QR code or a server address and token.
- Browse provider feeds, search titles, explore seasons and episodes, and manage your library and watch progress.
- Play streams locally with Media3 ExoPlayer, styled ASS subtitles, audio/subtitle selection, and source priority profiles with automatic fallback.
- Use touch gestures on phones and tablets, or D-pad navigation and media controls on Android TV.
- Send playback between connected Cloudstream clients and control other players from the app.
- Manage server plugins and browser challenges from Settings.

## Requirements and limitations

- Requires Android 8.0 or later and a reachable Cloudstream server. Use server 0.0.1 with this initial client release; plugins run on the server.
- Provider availability and playback depend on the plugin and stream. Some providers require Chromium on the server or an interactive browser challenge.
- Casting receivers must have their Cloudstream client open and receiving enabled.
