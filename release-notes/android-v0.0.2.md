# Android 0.0.2

## Changes

- Check for stable Android releases from Settings > App updates, download updates with progress and cancellation, and open Android's installer after checksum verification. Update checks work without a reachable desktop server.
- Use a narrower TV navigation rail and a single scrolling title page with details and episodes.
- Selecting Home now returns to the catalog instead of reopening a saved title page.
- Hide player controls immediately during hold-to-speed playback.
- Refresh the launcher icon and TV banner.
